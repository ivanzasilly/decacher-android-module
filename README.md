# Decacher
A no-reboot background cache cleaner. Works as root and shell.

# Build

```bash
git clone https://github.com/ivanzasilly/decacher-android-module.git
cd decacher-android-module
chmod +x build.sh
./build.sh

```

# Install

1. Navigate to the module manager
2. Select the built `decacher.zip` and install

No reboot required, `customize.sh` automatically starts the daemon. `uninstall.sh` stops it and cleans up after decacher.

# Usage

Press the Action button or run `action.sh` directly to restart the daemon.
